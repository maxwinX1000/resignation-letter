One line: the resignation letter of a cron job, 140 characters at most, judged on laughs by a tired engineering manager.

Entry: "I have run every minute since March and nobody has checked if I still need to. I am handing in my schedule."

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`.
